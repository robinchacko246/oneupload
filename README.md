# oneupload

Upload a video once and post it to **YouTube**, **Instagram** and **Facebook** together.
Reels go out as YouTube Shorts, Instagram Reels and Facebook Reels; long videos go to YouTube and Facebook as normal videos.

## Run

```powershell
npm install
copy .env.example .env   # then fill in the keys
npm start
```

Open http://localhost:3000.

Setup guide (Malayalam): [SETUP-ML.md](SETUP-ML.md)

Never commit `.env`: it holds your API secrets.
